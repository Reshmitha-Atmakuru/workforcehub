## How to Capture

1. Run the application: `npm run dev` (frontend) and `mvn spring-boot:run` (backend)
2. Open browser → `http://localhost:3000`
3. Login with `admin / password123`
4. Use your OS screenshot tool (Win+Shift+S on Windows) to capture each page
5. Save as PNG in this `/screenshots` folder
